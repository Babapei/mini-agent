## 题目 ：股票行情看板
### 做题时间：建议1天以内

### 业务背景

为个人投资者构建一个轻量级股票行情看板，支持搜索股票、管理自选列表、查看 K 线图，数据实时（或准实时）刷新。核心考察：**数据展示、图表渲染、性能优化**。

### 核心需求（必须完成）

1. **股票搜索**：输入股票代码或名称，展示匹配结果
2. **自选股管理**：添加/删除自选股，列表展示实时价格与涨跌幅
3. **K 线图**：选中股票后展示日 K 线图（至少支持最近 60 个交易日）
4. **数据刷新**：定时刷新行情数据（模拟或真实 API），价格变动有视觉反馈

### 加分项

- WebSocket 实时推送
- Canvas/WebGL 渲染 K 线（大数据量性能优化）
- 多周期切换（日 K、周 K、月 K）
- 技术指标叠加（MA5、MA20、MACD）
- 暗色主题
- 国际化（中/英）

**K 线数据生成规则（`kline_generator.md`）：**

由于无法使用真实行情 API，请基于以下规则生成模拟数据：

```
基准价格：
- 600519 贵州茅台: 1680.00
- 000858 五粮液: 145.00
- 300750 宁德时代: 210.00
- 601318 中国平安: 48.50
- 000001 平安银行: 11.20
- 600036 招商银行: 35.80
- 002594- 002594 比亚迪: 265.00
- 601899 紫金矿业: 18.60
- 688981 中芯国际: 78.50
- 000725 京东方A: 4.35

生成规则：
1. 每只股票生成最近 120 个交易日的 OHLCV 数据
2. 每日开盘价 = 前一日收盘价 × (1 + random(-0.02, 0.02))
3. 每日收盘价 = 开盘价 × (1 + random(-0.03, 0.03))
4. 最高价 = max(开盘价, 收盘价) × (1 + random(0, 0.015))
5. 最低价 = min(开盘价, 收盘价) × (1 - random(0, 0.015))
6. 成交量 = base_volume × random(0.5, 2.0)，base_volume 按股票流通市值估算
7. 日期跳过周末，从 2025-01-02 开始
```

**实时行情刷新模拟规则：**

```
每 3 秒刷新一次当前价格：
- 新价格 = 当前价格 × (1 + random(-0.005, 0.005))
- 涨跌幅 = (新价格 - 昨收) / 昨收 × 100%
- 涨：红色（#E74C3C）；跌：绿色（#27AE60）；平：灰色
- 价格变动时，数字有短暂闪烁动画（200ms）
```
